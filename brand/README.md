# Gentle King logo files

The logo is the gold crown with the name set beside it in EB Garamond, the same as the
header of the site. Use the **light** files on white or light backgrounds and the
**dark** files on dark ones. Every PNG has a see-through background.

| File | What it is |
| --- | --- |
| `gentle-king-logo-light.png` | The full logo, crown and name, for light backgrounds. 2248 by 576. |
| `gentle-king-logo-dark.png` | The full logo, crown and name, for dark backgrounds. 2248 by 576. |
| `gentle-king-crown-light.png` | The crown alone, for light backgrounds. 1280 by 1216. |
| `gentle-king-crown-dark.png` | The crown alone, for dark backgrounds. 1280 by 1216. |
| `gentle-king-crown-light.svg` | The crown alone, for light backgrounds. Sharp at any size, even in print. |
| `gentle-king-crown-dark.svg` | The crown alone, for dark backgrounds. Sharp at any size, even in print. |
| `gentle-king-icon-512.png` | The app icon, the gold crown on a dark rounded square. 512 by 512. |
| `gentle-king-icon.svg` | The app icon, as an SVG. The same as the browser tab icon. |

The colors are the site's own.

| Where | Light | Dark |
| --- | --- | --- |
| Crown | `#7d5f34` | `#c9a227` |
| Name | `#1c1a17` | `#ece6d9` |
| Icon square | | `#1c1a17` |

The name is EB Garamond at weight 500. The font files are in `assets/fonts/`, and it is
free under the SIL Open Font License.

To download a file, open it here on GitHub and choose the download button at the top
right of the file.
