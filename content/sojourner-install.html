The first time

Installing It

Download the installer from the releases page and run it. It installs for you alone, so it needs no administrator rights. It bundles the Microsoft Edge WebView2 runtime that Sojourner draws with, so it installs on a machine that has never been online.

One installer holds everything but the book library. The books come as four shelves, each its own download, and they are on the releases page too, further down, under Sojourner Library Packs. Adding a shelf is set out below.

New to the program? A tutorial built into it walks through every feature. You will find it in Settings, under Tutorial.

Before you double-click

Two Honest Warnings

Neither of these is a problem with the program, but you should know about both before you double-click anything.

Windows will warn you. The installer is not code-signed, because a certificate costs money this work does not have. So SmartScreen shows a blue box the first time you run it. Click More info, then Run anyway. The release page lists the installer’s SHA-256 checksum, a kind of fingerprint for the file, so anyone who knows how can confirm the file is the one that was published. The installer is built by GitHub from the public source code, not on anyone’s own computer, and the release page links the record of that build. If the warning makes you uneasy, that instinct is a good one, and you are welcome to pass on it.

It is a large download. About {{size}} MB, because the texts and the reading voice are all inside it rather than fetched from a server later. That is the trade. One long download once, and then the program never needs the network again.

Version {{version}} means what it says. This is early, real, and in use, but it is not finished. Things will change and some of them will break. If something goes wrong, tell me and I will fix it.

A new version

Updating

Sojourner does not update itself. To see whether a newer version exists, open the About page in Settings and press the button there. That button is the only thing in the program that goes online. Then download the new installer and run it over the old one.

Your notes, highlights, sermons, prayers, bookmarks, and installed shelves are all kept. Even so, make a backup first. You will find it in Settings, under Data and backups.

This version brings Color text, which puts every person, place, time, and number in the Bible in its own color, and Who’s speaking, which sets God’s own words apart from the story around them.

Library packs

The Book Shelves and the Map Packs

The book shelves are on the releases page under Sojourner Library Packs 0.3.6, with two map packs that give the Atlas its hills and a view from the sky. To install one, open Settings, choose Library packs, and pick Install or update a shelf. What is on each shelf is set out with the rest of the library.

If your Puritan and Reformed shelf is older than 0.3.6, install the new one. It was rebuilt from cleaner texts, and it takes the old one’s place and keeps your notes on its books. The other three shelves have the same books as before, so they work as they are.

The map packs need Sojourner 0.3.6 or later. To add one, open Settings, choose Library packs, and pick Install a map pack. What each pack shows is described with the atlas. Like the shelves, they come as files you download yourself, so they can just as well arrive on a USB stick.

If something goes wrong

Bug Reports and Corrections

If something does not work, or a text is wrong, or you want the program to do a thing it does not do, write to sojourner at gentleking.org. Bug reports are genuinely welcome, and corrections to the texts most of all.
