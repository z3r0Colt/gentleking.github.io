The first time

Installing It

Go to the releases page and download the one file for your computer. All three hold the same full program. On a phone, a tablet, or a Mac, use Sojourner in the browser instead.

On Windows

Download the file ending in x64-setup.exe and run it. It installs for you alone, so it doesn’t need administrator rights. It includes the Microsoft Edge WebView2 runtime that Sojourner draws with, so it installs on a machine that has never been online. It runs on Windows 10 or 11, 64-bit.

On Linux

Sojourner needs a 64-bit Linux system from 2024 or later.

  1. Ubuntu 24.04, Linux Mint 22, Debian 13, or newer. Download the file ending in .deb and open it in your software installer. Or, in a terminal in the folder where it landed, run sudo apt install ./Sojourner_{{version}}_amd64.deb.
  2. Most other systems, such as Fedora 40 or newer. Download the file ending in .AppImage. It runs without installing. Make it executable, then open it. You can do that in its Properties by allowing it to run as a program, or with chmod +x in a terminal. It needs the libfuse2 package, which Ubuntu 24.04 calls libfuse2t64.

Moving from Windows to Linux? On the Windows computer, open Settings, choose Data and backups, and Export. Copy that file across, then choose Import in the same place on Linux.

The book library isn’t in any of the three. The books come as four shelves, each a separate download. They’re further down the releases page, under Sojourner Library Packs. The same shelf files work on Windows and Linux. Adding a shelf is explained below.

New to the program? A built-in tutorial walks through every feature. It’s in Settings, under Tutorial.

Before you double-click

Two Things to Know First

Neither of these is a problem with the program, but you should know about both.

Windows will warn you. The Windows installer isn’t code-signed, because a certificate costs money this work doesn’t have. So SmartScreen shows a blue box the first time you run it. Click More info, then Run anyway. The release page lists each file’s SHA-256 checksum, a kind of fingerprint for the file. Anyone who knows how can use it to confirm the file is the one that was published. All three files are built by GitHub from the public source code, not on anyone’s own computer. The release page links the record of that build. If the warning makes you uneasy, that’s a good instinct, and you’re welcome to pass on it.

It's a large download. That’s the trade. One long download once, and then the program never needs the network again.

Version {{version}} means what it says. It’s early, real, and in use, but it isn’t finished. Things will change and some of them will break. If something goes wrong, tell me and I’ll fix it.

A new version

Updating

Sojourner doesn’t update itself. To see whether a newer version exists, open the About page in Settings and press the button there. That button is the only thing in the program that goes online. On Windows, download the new installer and run it over the old one. On Linux, install the new .deb the same way you installed the first, or put the new AppImage in place of the old one.

Your notes, highlights, sermons, prayers, bookmarks, and installed shelves are stored apart from the program, and they’re kept. Even so, make a backup first, in Settings under Data and backups.

Version 0.4.1 brought Sojourner to Linux, the same program with everything the Windows version has. Version 0.4.0 brought Color text, which puts every person, place, time, and number in the Bible in its own color, and Who’s speaking, which sets God’s own words apart from the story around them.

Library packs

Adding Books and Maps

The book shelves are on the releases page under Sojourner Library Packs 0.3.6, with two map packs that add terrain and satellite views to the Atlas. To install one, open Settings, choose Library packs, and pick Install from file. Once a shelf is in, that button reads Install or update a shelf. What is on each shelf is listed with the rest of the library.

If your Puritan and Reformed shelf is older than 0.3.6, install the new one. It was rebuilt from cleaner texts. It replaces the old one and keeps your notes on its books. The other three shelves have the same books as before, so they work as they're.

The map packs need Sojourner 0.3.6 or later. To add one, open Settings, choose Library packs, and pick Install a map pack. What each pack shows is described with the atlas. Like the shelves, they’re files you download yourself, so they can also come on a USB stick.

If something goes wrong

Bug Reports and Corrections

If something doesn’t work, or a text is wrong, or you want the program to do something it doesn’t, write to sojourner at gentleking.org. Bug reports are welcome, and corrections to the texts most of all.
